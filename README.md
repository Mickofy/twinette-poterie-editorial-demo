# Twinette Poterie — Independent Editorial Concept

An unofficial, independently created Shopify homepage redesign concept by [MICKOFY](https://mickofy.com).

**Live preview:** https://twinette-poterie-editorial-demo.pages.dev/

## Purpose

A visual exploration of a more editorial Shopify storefront for Twinette Poterie, using its existing brand, ceramic collections, and artisan storytelling.

This is **not** Twinette Poterie's official website. It is not affiliated with, endorsed by, or commissioned by the business.

## Implementation

- Responsive static HTML/CSS/JavaScript; all primary styling, scripts, and preview photos are embedded in `index.html`.
- Catalog, collections, search, and journal links lead to the official merchant storefront; there is no mock checkout or Shopify backend.
- Some content images load from the original Shopify CDN and may change or become unavailable.
- Placeholder brand wordmark and imagery extracted from visual references are for concept illustration only; original, approved brand assets should be used before any official implementation.
- Product names, prices, availability, and article content should be verified against the current store before sending as a final commercial proposal.
- The preview includes a visible independent-concept notice and asks search engines not to index it.

## Shopify feasibility

The main elements can be rebuilt as editable Shopify Online Store 2.0 sections with Liquid and theme settings, native product/collection data, accessible navigation, and responsive image rendering.
